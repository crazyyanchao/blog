# 阿里云ECS手动部署镜像

## 1. 在源服务器操作
```bash
# 下载并保存镜像
docker pull docker.io/grapher01110/n8n-amir:latest
docker save -o n8n-amir.tar grapher01110/n8n-amir:latest

# 压缩镜像文件（可选）
tar -czf n8n-amir.tar.gz n8n-amir.tar
```

## 2. 上传到阿里云OSS

通过宝塔操作：
安装宝塔OSS插件或在宝塔文件管理直接上传
或者使用OSS Browser工具上传
或手动上传指定位置。

通过命令行上传：
```bash
# 安装OSSutil
wget http://gosspublic.alicdn.com/ossutil/1.7.13/ossutil64
chmod +x ossutil64

# 配置OSS（需要AccessKey）
./ossutil64 config

# 上传文件
./ossutil64 cp n8n-amir.tar oss://your-bucket-name/
```
